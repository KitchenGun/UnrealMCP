# Rules 디렉토리

실패할 때마다 여기에 규칙을 추가합니다.

## 규칙 파일 형식

### .md -- 사람이 읽는 규칙 설명
왜 이 규칙이 생겼는지, 어떤 실패에서 왔는지 기록합니다.

### .sh -- 린터가 실행하는 자동 검사
`./scripts/lint.sh`가 이 디렉토리의 모든 .sh를 실행합니다.
첫 번째 인자가 "true"이면 자동 교정 모드입니다.

```bash
#!/bin/bash
# 규칙 스크립트 템플릿
FIX=${1:-false}
FOUND=0
# 검사 로직...
[ $FOUND -gt 0 ] && exit 1
exit 0
```
